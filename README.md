# kroki-editorial-diagrams
A premium, unified diagramming skill designed for **Claude Code** (and similar agentic workflows).  It combines **auto-layout multi-engine diagrammatic DSLs** (PlantUML, C4, D2, Mermaid, Graphviz, ERD) with the **aesthetic styling guidelines** of high-end editorial design, featuring **interactive SVG wrappers** and **automated gallery indexing**.
