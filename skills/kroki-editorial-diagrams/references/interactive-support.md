# Interactive Support Reference

Our Python tool `build_interactive_kroki_html.py` parses plain SVGs generated by Kroki and injects browser logic to support:

* Click-to-highlight node focus.
* Dimming of unrelated nodes/edges.
* Flow indicators on edges (animated path offsets).

---

## 1. Engine Animation Support Tiers

### Full Interactivity

Full tier: click-to-highlight node focus, connected edge animation, dimming of inactive elements, pan/zoom.

| Engine | Parsing Mechanism |
| --- | --- |
| **PlantUML** | Matches sequence participant IDs and descriptions. |
| **C4-PlantUML** | Same annotation path as PlantUML (entity/link class groups). |
| **D2** | Uses same `class="node"` / `class="edge"` SVG conventions as Graphviz. |
| **Graphviz** | Evaluates `class="node"` / `class="edge"` groups with `<title>` text. |

### Best-Effort Interactivity

Best-effort tier: node focus and/or edge dimming; flow animation uses vertical fallback. Pan/zoom always available.

| Engine | Parsing Mechanism |
| --- | --- |
| **Mermaid** | Matches element IDs of type `flowchart-link`. |
| **ERD** | Graphviz-style parsing attempted; structural metadata is limited. |
| **Structurizr** | Graphviz-style `class="node"` / `class="edge"` parsing attempted; may degrade to limited if SVG structure differs across Kroki versions. |

### Limited (Pan/Zoom Only)

Limited tier: no node/edge annotation available in SVG output. Pan, zoom, and keyboard navigation only.

| Engine | Reason |
| --- | --- |
| **BPMN** | No structural metadata in SVG output from the bpmn-js renderer. |
| **WaveDrom** | Signal-based SVG with no graph node/edge structure. |
| **Vega / Vega-Lite** | Canvas-based or SVG chart output with no graph topology. |
| **Excalidraw** | Hand-drawn raster-style SVG; no node/edge class attributes. |
| **Diagrams.net** | Vendor-specific SVG; no parseable node/edge classes. |
| **Nomnoml** | Limited SVG metadata — falls back to limited after annotation attempt. |
| **Ditaa / SvgBob / GoAT** | ASCII-art render; no graph structure in SVG output. |
| **Pikchr / Bytefield / WireViz** | Specialist SVG with no standard graph class annotations. |
| **BlockDiag family** | Basic SVG with no parseable node/edge class attributes. |
| **Symbolator / UMLet** | Hardware/UML-specific SVG; no standard graph structure. |

## 2. Interactive Hotkeys in Browser

When exploring any generated `interactive.html` document:

* **Spacebar (Hold) + Drag**: Pan around the canvas smoothly.
* **Mouse Scroll**: Zoom in / zoom out.
* **Arrow Keys**: Move/pan the camera.
* **`+` / `-`**: Direct zoom.
* **`0`**: Auto-fit the diagram layout to the viewport.
* **`1`**: Reset zoom level to exactly 100%.
* **Click Node**: Focuses node, highlights connected edges with animated glow, and dims everything else.
* **Click Blank Space**: Clears active selection and restores full diagram state.
