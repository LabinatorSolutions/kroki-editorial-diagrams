# Interactive Support Reference

Our Python tool `build_interactive_kroki_html.py` parses plain SVGs generated by Kroki and injects browser logic to support:

* Click-to-highlight node focus.
* Dimming of unrelated nodes/edges.
* Flow indicators on edges (animated path offsets).

---

## 1. Engine Animation Support Tiers

| Engine          | Parsing Mechanism                                                      | Interactivity Tier                                                                   |
| --------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **PlantUML**    | Matches sequence participant IDs and descriptions.                     | **Full** (Node focus, edge connections, and directional offset flow).                |
| **C4-PlantUML** | Same annotation path as PlantUML (entity/link class groups).           | **Full** (Node focus, edge highlight, directional flow animation).                   |
| **D2**          | Uses same `class="node"` / `class="edge"` SVG conventions as Graphviz. | **Full** (Node focus, edge highlight, directional flow animation).                   |
| **Graphviz**    | Evaluates `class="node"` / `class="edge"` groups with `<title>` text.  | **Full** (Calculates vertical flow vectors).                                         |
| **Mermaid**     | Matches element ids of type `flowchart-link`.                          | **Best Effort** (Node focus, edge dimming; flow animation is vertical fallback).     |
| **ERD**         | Lacks rich structural metadata in XML headers.                         | **Best Effort** (Graphviz-style parsing attempted; panning & zoom always available). |
| **BPMN**        | No structural metadata available in SVG output.                        | **Static/Limited** (Panning & zoom controls only).                                   |

---

## 2. Interactive Hotkeys in Browser

When exploring any generated `interactive.html` document:

* **Spacebar (Hold) + Drag**: Pan around the canvas smoothly.
* **Mouse Scroll**: Zoom in / zoom out.
* **Arrow Keys**: Move/pan the camera.
* **`+` / `-`**: Direct zoom.
* **`0`**: Auto-fit the diagram layout to the viewport.
* **`1`**: Reset zoom level to exactly 100%.
* **Click Node**: Focuses node, highlights connected edges with animated glow, and dims everything else.
* **Click Blank Space**: Clears active selection and restores full diagram state.
